Multi-Client File and System Information Server made using code generated by Gemini 3.8 Flash.

A high-performance, concurrent Java client-server application built using native Java TCP socket programming (`ServerSocket` and `Socket`) without any third-party network frameworks.

Compilation and Build

Using Maven (Recommended)
Package the server and client into standalone runnable JAR files:
```bash
mvn clean package
```
This generates:
- `target/server.jar`
- `target/client.jar`

Using standard `javac` (No Maven required)
```bash
# From the project root:
javac -d bin src/main/java/com/networks/common/*.java src/main/java/com/networks/server/auth/*.java src/main/java/com/networks/server/file/*.java src/main/java/com/networks/server/logging/*.java src/main/java/com/networks/server/system/*.java src/main/java/com/networks/server/*.java src/main/java/com/networks/client/ui/*.java src/main/java/com/networks/client/*.java
```

Running the Application

Option 1: Running with JARs

On Computer/Process 1 (Server):
```bash
java -jar target/server.jar 8888
```

On Computer/Process 2 (Client):
```bash
java -jar target/client.jar <SERVER_IP> 8888
```
*(For local testing on one computer, use `localhost` or `127.0.0.1`)*

Option 2: Running with Compiled Classes (`javac`)

Start Server:
```bash
java -cp bin com.networks.server.ServerMain 8888
```

Start Client(s):
```bash
java -cp bin com.networks.client.ClientMain localhost 8888
```

Application Protocol Overview

| Command | Arguments | Description |
|---|---|---|
| `LOGIN` | `<username> <password>` | Authenticates client. Connection closes on 3 failures. |
| `LIST` | none | Lists files in storage directory. |
| `UPLOAD` | `<filename> <filesize>` | Uploads file bytes to server under write lock. |
| `DOWNLOAD` | `<filename>` | Downloads file bytes from server under read lock. |
| `DELETE` | `<filename>` | Deletes file from server under exclusive write lock. |
| `INFO` | `<filename>` | Returns creation, modification, size, and lock info. |
| `TIME` | none | Returns server's current date/time. |
| `UPTIME` | none | Returns time elapsed since server started. |
| `MEMORY` | none | Returns JVM memory utilization stats. |
| `CLIENTS` | none | Returns count of active connected clients. |
| `THREADS` | none | Returns active JVM threads count. |
| `EXIT` | none | Closes connection. |
