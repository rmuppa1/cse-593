Multi-Client File and System Information made using code generated by Copilot pro in auto mode which used the model Claude Sonnet 5.5.

Pure Java (17+) TCP client/server. The server uses a fixed thread pool (20), so many clients run concurrently.

To Build
    mvn package

or without Maven (PowerShell):

    mkdir out
    javac -d out (Get-ChildItem -Recurse src -Filter *.java).FullName

To Run
Server (default port 5000, storage `server-storage/`):

    java -cp out com.networks.server.ServerMain [port] [storageDir]

Client (can run on another machine; enter the server's IP when prompted):

    java -cp out com.networks.client.ClientMain
